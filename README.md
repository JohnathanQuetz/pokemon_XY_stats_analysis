# Pokémon XY Base Stats Analysis

## Overview
This project performs exploratory data analysis (EDA) and statistical hypothesis testing on Pokémon base stat distributions using Python. The goal is to analyze base stats of Pokémon and evaluate differences between legendary and non-legendary Pokémon.

---

## Research Questions
1. What is the total base stat of an average Pokémon?
2. Do legendary Pokémon have statistically higher total base stats than non-legendary Pokémon?
3. Is there a relationship between special attack/defense and regular attack/defense statistics?

---

## Methods Used
- Exploratory Data Analysis (EDA)
- Median as measure of central tendency
- IQR-based outlier detection and removal
- Pearson correlation analysis
- One-tailed z-test hypothesis testing
- Data visualization (histograms and scatterplots)

---

## Key Results
- Median total base stat: **450**
- Legendary Pokémon have statistically higher mean total base stats (α = 0.05)
- Moderate positive correlation (r ≈ 0.47) between special and regular attack/defense sums
